# Benevia.mx | versión 2026-09-12

Sitio estático completo, listo para publicar con la misma estructura de despliegue del paquete recibido.

## Actualización de esta versión

- Se sustituyó la página principal por la nueva versión centrada en el momento en que el futuro de la empresa empieza a preocupar.
- La portada conserva la arquitectura visual Benevia y desarrolla el recorrido completo hasta profesionalización, forma de trabajo y cierre.
- No se modificó el contenido de `articulos.html` ni de ninguno de los 12 artículos de la carpeta `articulos/`.
- Las páginas interiores, imágenes, redirecciones, `robots.txt`, `sitemap.xml`, `script.js` y configuración de Cloudflare se conservan del paquete anterior.

## Dirección visual

- Identidad editorial y sistémica, con azul noche como arquitectura principal y la paleta Benevia usada como código funcional.
- Tipografías web: Sora para títulos, IBM Plex Sans para lectura e IBM Plex Mono para señalización.
- Sin fotografías corporativas genéricas ni recursos visuales que compitan con el argumento.
- Navegación y jerarquía adaptadas a escritorio y móvil.

## Publicación

La estructura, `_redirects`, `robots.txt`, `sitemap.xml` y `wrangler.jsonc` se conservan para el flujo de publicación existente en Cloudflare.

El formulario de `contacto.html` conserva el endpoint Formspree del sitio fuente: `https://formspree.io/f/xdabwwzv`.

No se incorporó un token de analítica porque el paquete fuente no contenía uno real. El sitio funciona sin analítica y puede publicarse así; Cloudflare Web Analytics puede añadirse posteriormente sin modificar el diseño.

## Ajuste visual 15-sep-2026
La página principal conserva íntegramente su contenido y redacción. Se cambió únicamente su composición visual: lectura vertical, títulos sobre el texto, menos alternancia de fondos y rupturas visuales reservadas para momentos clave. Los artículos y páginas interiores no fueron modificados.
