# Benevia.mx | versión 2026-09-15

Sitio estático completo, listo para publicar con la misma estructura de despliegue del paquete anterior.

## Actualización de esta versión

- Se conserva la composición editorial vertical de la página principal.
- Se actualizó el inicio con cuatro situaciones reconocibles: hijos que llegan, crecimiento, cambio de mercado y salida de una persona clave.
- La frase “Casi siempre hay algo concreto detrás.” funciona como encabezado de segundo nivel y los cuatro temas como encabezados de tercer nivel, con tratamiento tipográfico propio.
- La sección “Cuando algo cambia” fue sustituida por “Poner a alguien más no basta”, con el nuevo desarrollo y cierre acordados.
- No se modificó el contenido de `articulos.html` ni de ninguno de los 12 artículos de la carpeta `articulos/`.
- Las demás páginas interiores, imágenes, redirecciones, `robots.txt`, `sitemap.xml`, `script.js` y configuración de Cloudflare se conservan del paquete anterior.

## Dirección visual

- Lectura vertical con títulos sobre el texto.
- Azul noche, papel y acentos de la paleta Benevia usados con sobriedad.
- Sora para títulos, IBM Plex Sans para lectura e IBM Plex Mono para señalización.
- Los H3 del bloque inicial tienen jerarquía propia sin convertirse en tarjetas ni categorías de servicios.
- Las rupturas visuales se reservan para momentos argumentales importantes.

## Publicación

La estructura, `_redirects`, `robots.txt`, `sitemap.xml` y `wrangler.jsonc` se conservan para el flujo de publicación existente en Cloudflare.

El formulario de `contacto.html` conserva el endpoint Formspree del sitio fuente: `https://formspree.io/f/xdabwwzv`.
